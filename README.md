# BACAQUEST v1.0

Permainan web literasi berdasarkan struktur Buku Poket Bijak Baca.

## Cara guna
1. Ekstrak fail ZIP.
2. Buka `index.html` menggunakan Chrome / Edge.
3. Masukkan nama murid.
4. Main Level 1 hingga Level 33.

Tidak memerlukan pemasangan server.

## Fungsi
- 33 level.
- 9 dunia pembelajaran.
- XP, coin, nyawa, bintang dan streak.
- Power-up: Hint, Shield, Skip, Double XP.
- Level unlocking.
- Badge.
- Final Boss.
- Dashboard guru asas.
- Data disimpan menggunakan `localStorage`.

## Catatan
Versi ini ialah MVP statik satu peranti. Untuk kegunaan sekolah berbilang murid/peranti,
naik taraf seterusnya disyorkan menggunakan Supabase/Firebase untuk:
- Login guru/murid.
- Data kelas.
- Rekod kemajuan pusat.
- Leaderboard kelas.
- Audio bacaan.
- QR mengikut level.
- Pelaporan intervensi.
